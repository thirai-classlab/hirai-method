# → プロンプトでシークレット値を貼り付けると、Vercel側に暗号化保存される

# 5. デプロイして差分を確認
vercel --prod
# → 新トークン・新環境変数で正常にビルドが通るか検証される

ハンズオン（ジュニアエンジニア向け）

Ollamaで Kimi K2.6 をローカル起動（所要時間: 20分、RAM 64GB推奨のため個人PCでは量子化版を使用）:

# 1. Ollamaインストール（macOS）
brew install ollama
# → llama.cpp互換のローカルLLMランタイムがインストールされる

# 2. Ollamaサーバー起動
ollama serve &
# → localhost:11434でOpenAI互換APIが立ち上がる

# 3. Kimi K2.6の量子化版をプル
ollama pull kimi-k2.6
# → Hugging Face経由でINT4量子化済みの重みをダウンロード（数十GB）

# 4. CLIで対話
ollama run kimi-k2.6 "ClassLab.のServiceGuide__cオブジェクトに電気契約終了日フィールドを追加するApexトリガーを書いて"
# → Apex + テストクラスのひな形が日本語コメント付きで生成される

# 5. OpenAI互換API経由でClaude Codeから呼び出す
export OPENAI_BASE_URL=http://localhost:11434/v1
export OPENAI_API_KEY=ollama
# → 既存のOpenAI SDKコードをコード変更なしでKimi経由に切り替えられる

活用例3選:

  1. ServiceGuide__cオブジェクトの電気／ガス／水道／ネット契約フィールド追加リクエストをKimi K2.6に自動コード化させ、Claude Codeと出力品質を比較

# → 参考デザインを下敷きとしてプロジェクト直下に配置

# 4. DESIGN.mdを自社ブランドに合わせて編集
