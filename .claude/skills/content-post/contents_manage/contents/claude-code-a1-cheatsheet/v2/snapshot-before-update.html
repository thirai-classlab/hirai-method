🚀 起動オプション（CLI）

ターミナルで claude コマンドの後ろにつけるフラグ（起動オプション）の一覧です。よく使うやつから順に並べました。

基本

コマンド説明
claudeインタラクティブセッション開始
claude "<prompt>"プロンプトを与えて起動
claude -p "<prompt>"出力モード（パイプ向き）
claude --versionバージョン表示
claude --helpヘルプ

セッション管理

「昨日の続きから」をやりたいときの定番。-c だけ覚えておけば9割なんとかなります。

コマンド説明
claude -c直前のセッションを再開
claude -rセッション一覧から選んで再開
claude -r <session-id>ID指定で再開
claude --resume-r と同じ
claude --teleportWeb/モバイルで開始したセッションを引き継ぐ
claude --fork-sessionセッションを分岐

モデル / 思考量

どのモデル（Opus / Sonnet / Haiku）で起動するかの指定です。

コマンド説明
claude --model opusOpus で起動
claude --model sonnetSonnet で起動
claude --model haikuHaiku で起動
claude --model opusplanPlan = Opus / Exec = 別
claude --effort max最大思考モード

モード切替

コマンド説明
claude --planプランモードで起動
claude --auto-edit編集自動承認
claude --dangerously-skip-permissions⚠️ 全権限スキップ（サンドボックス専用）

⚠️ --dangerously-skip-permissions は名前の通り危険なやつなので、Docker などのサンドボックス環境以外では絶対に使わない でください。

スクリプト連携（パイプ）

-p をつけると、他のコマンドの結果を Claude に流し込めます。CI や自動化でよく使うパターン。

# ファイル内容を渡す
cat error.log | claude -p "このログを分析"

# CIでの自動レビュー
git diff main --name-only | claude -p "変更ファイルをセキュリティ観点でレビュー"

# tail と組み合わせる
tail -200 app.log | claude -p "Slackで通知すべき異常があれば教えて"

出力フォーマット

コマンド説明
claude -p --output-format jsonJSON出力
claude -p --output-format textテキスト
claude -p --output-format markdownMarkdown

🔐 パーミッション

パーミッション（権限の厳しさ）の設定方法。settings.json に書いておくと、毎回確認されるストレスが減ります。

評価順

Deny → Ask → Allow

上から順にチェックされます。Deny に書いたものは絶対ブロック、Ask は確認、Allow は自動許可。「禁止」が一番強い と覚えておけば OK。

settings.json での書き方

{
  "permissions": {
    "allow": [
      "Bash(npm test)",
      "Bash(npm run *)",
      "Bash(git status)",
      "Read(*)",
      "Edit(src/**)"
    ],
    "ask": [
      "Bash(git push:*)",
      "Bash(npm install:*)"
    ],
    "deny": [
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)",
      "Bash(rm -rf:*)",
      "Bash(sudo:*)",
      "Bash(git push --force:*)"
    ]
  }
}

よくあるパターン

パターン説明
Bash(git status)git status 完全一致
Bash(git status:*)git status で始まるすべて
Read(./src/**)src/ 以下の全ファイル読み込み
Read(./.env*).env で始まるファイル全部

🔧 MCP管理

MCP（外部ツールとの接続規格）サーバーを追加・削除するときのコマンド。

# 追加
claude mcp add <name> <command> [-- <args>]

# 環境変数付きで追加
claude mcp add github -e GITHUB_TOKEN=ghp_xxx -- npx -y @modelcontextprotocol/server-github

# 一覧
claude mcp list

# 削除
claude mcp remove <name>

# 接続確認
/mcp

📦 skills.sh CLI

スキル（Claude に「こういうときはこうやって」と教える小さい指示集）を npm 経由で管理するツール。

# 検索
npx skills find <keyword>

# インストール
npx skills add <owner/repo@skill> [-g] [-y]

# 一覧
npx skills list

# 更新確認
npx skills check

# 全更新
npx skills update

# 自作スキル初期化
npx skills init <skill-name>
