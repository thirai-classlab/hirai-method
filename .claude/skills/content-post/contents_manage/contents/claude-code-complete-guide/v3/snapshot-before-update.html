🎯 このシリーズについて

社内向け Claude Code 勉強会 の正式テキストです。

全14回（第0回〜第14回）+ 付録3冊（A・B・C） = 約11時間

Claude Code は、Anthropic 公式の AIエージェント です。「LLM（Large Language Model = 大規模言語モデル）」に手足と道具を持たせたもので、ターミナルから呼び出すだけで、ファイルを読み書きしたり、コマンドを実行したり、外部サービスを呼んだりできます。

このシリーズでは、「ターミナルって何?」レベル から始めて、「自分の業務を Claude Code で自動化する」 ところまで、地続きで案内します。コードが書けなくても、最初の数回を読めば使い始められます。
