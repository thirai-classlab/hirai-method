## 🎨 画像生成の方針（ユーザ指示）

### 参照スタイル

ユーザが指定した参照画像: `https://d2f75plg0t6qwk.cloudfront.net/thumbnail-gallery/t374-sketchnote-20260426-061945-1.webp`

**スケッチノート風** = 手書きホワイトボード、パステルカラー、吹き出し、絵文字、星マーク、傾いたバッジ、点線円。

### 必守ルール

1. **テイストのみ参照、内容は元設計を維持** — 元PNGの情報構造（4段モデル / Master-Detail比較 / 7ステップ等）を保持
2. **画像内テキストは日本語SF UI公式表記** — `Master-Detail` → 主従関係、`Page Layout` → ページレイアウト など。固有名詞 (Apex/Lightning/Salesforce/__c) のみ英語可
3. **トリミング時に見切れない** — 全コンテンツが余白を持って canvas 内に収まる
4. **元のローカルファイルパスに上書き保存** — post.ts が SHA-256 ハッシュを再計算して新キーで CDN にアップロード、旧キーを invalidate

### ai-image-gen スキルの使い方

**SKILL場所**: `/Users/t.hirai/.claude/skills/ai-image-gen/SKILL.md`

**呼び出し**:
```bash
cd ~/.claude/skills/ai-image-gen
set -a && source .env && set +a
node scripts/gen.mjs models                    # モデル一覧
node scripts/gen.mjs generate "<日本語プロンプト>" \
  --model openai/gpt-image-2 \                 # テキスト入り画像はこれ
  --size 1536x1024 \                           # gpt-image-2 のネイティブサイズ
  --out ~/work/雑務/.claude/skills/content-post/drafts/images/<slug>/
```

**推奨モデル**:
- **テキスト入り画像（タイポ重視）** → `openai/gpt-image-2`, `bfl/flux-2-flex`
- **手書きスケッチ風** → `bfl/flux-2-pro`（プロンプトで `hand-drawn whiteboard sketch` 指定）

**重要な注意（content-post SKILL.md より引用）**:
> 画像内のラベル・見出し・説明文は**原則すべて日本語**で書く
> 固有名詞のみ英字を許可（`Salesforce`, `AWS S3`, `CSV` 等）
> プロンプト末尾に「日本語のラベルのみ、英字は固有名詞のみ」を必ず入れる
> 文字混合防止のためボックス N に **1 つだけ** ◯◯ と書く と個数を断定
