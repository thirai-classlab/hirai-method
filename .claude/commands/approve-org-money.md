# /approve_org_money - 稟議書作成

## 概要

新規サービス/ツール導入またはリプレイス（乗り換え）の稟議書を対話形式で作成するコマンド。
金額比較表・移行期間コスト・年間コスト試算を自動計算し、Markdownで出力する。

## 使用方法

```
/approve_org_money [サービス名/ツール名]
```

引数なしの場合は対話で確認する。

## 実行フロー

### A-1: 申請種別の確認

ユーザーに以下を確認:

1. **申請種別**: 新規申請 or リプレイス
2. **サービス/ツール名**: 何を導入するか
3. **出力フォルダ名**: 稟議書の保存先フォルダ名（デフォルト: サービス名）

### A-2: 共通情報のヒアリング（新規・リプレイス共通）

以下の項目を対話で収集する:

| #   | 項目               | 説明                                    | 必須 |
| --- | ------------------ | --------------------------------------- | ---- |
| 1   | サービス/ツール名  | 導入するサービスの正式名称              | 必須 |
| 2   | カテゴリ           | SaaS / インフラ / ハードウェア / その他 | 必須 |
| 3   | 初回決済額（税込） | 初期費用・セットアップ費用等            | 必須 |
| 4   | 月額換算額（税込） | 月額にならした金額                      | 必須 |
| 5   | 契約プラン         | プラン名・ライセンス数等                | 必須 |
| 6   | 更新日             | 契約更新日（年次/月次/更新なし）        | 必須 |
| 7   | 契約期間           | 月単位 or 年単位（自動更新の有無）      | 必須 |
| 8   | 導入背景・理由     | なぜ今導入が必要か                      | 必須 |
| 9   | 期待効果           | 導入により何が改善されるか              | 推奨 |
| 10  | 決済方法           | クレジットカード / 請求書 / その他      | 推奨 |
| 11  | 利用者             | 利用する部署・人数                      | 推奨 |
| 12  | 備考               | その他特記事項                          | 任意 |

### A-3: リプレイス追加情報のヒアリング（リプレイスの場合のみ）

リプレイスの場合、A-2に加えて以下を収集:

| #   | 項目                           | 説明                       | 必須 |
| --- | ------------------------------ | -------------------------- | ---- |
| R1  | 現行サービス名                 | 置き換え元のサービス名     | 必須 |
| R2  | 現行月額（税込）               | 現在支払っている月額       | 必須 |
| R3  | 現行年額（税込）               | 現在の年間コスト           | 必須 |
| R4  | リプレイス完了予定日           | 移行完了目標日             | 必須 |
| R5  | 移行期間                       | 並行稼働の開始日〜完了日   | 必須 |
| R6  | リプレイス完了後の月額（税込） | 移行完了後に支払う月額     | 必須 |
| R7  | 現行サービスの解約条件         | 解約通知期限・違約金等     | 推奨 |
| R8  | リプレイス理由                 | 現行サービスの課題・不満点 | 必須 |

### A-4: コスト計算

#### 新規申請の場合

以下を自動計算:

- **初年度コスト**: 初回決済額 + (月額 x 残月数)
- **年間コスト**: 月額 x 12
- **3年間総コスト**: 初回決済額 + (月額 x 36)

#### リプレイスの場合

以下を自動計算:

**並行稼働期間コスト表**（月次）:

| 月          | 現行サービス | 新サービス | 合計    | 備考           |
| ----------- | ------------ | ---------- | ------- | -------------- |
| 移行1ヶ月目 | ¥XX,XXX      | ¥XX,XXX    | ¥XX,XXX | 並行稼働       |
| 移行2ヶ月目 | ¥XX,XXX      | ¥XX,XXX    | ¥XX,XXX | 並行稼働       |
| ...         | ...          | ...        | ...     | ...            |
| 移行完了後  | ¥0           | ¥XX,XXX    | ¥XX,XXX | 新サービスのみ |

**コスト比較サマリ**:

- 現行の年間コスト
- 移行期間の追加コスト（並行稼働分）
- リプレイス完了後の年間コスト
- 年間削減額 or 年間増加額
- 移行コスト回収期間（増加の場合はN/A）

### A-5: 稟議書生成

収集した情報とコスト計算結果を元に稟議書を生成する。

## コスト計算ルール

1. **金額はすべて税込表記**
2. **月額換算**: ユーザーが入力した月額をそのまま使用（年額プランの場合は年額÷12で算出）
3. **並行稼働コスト**: 移行期間の月数 x (現行月額 + 新サービス月額) で算出
4. **年間削減額**: 現行年額 - 新サービス年額
5. **回収期間**: 並行稼働追加コスト ÷ 月間削減額（削減がない場合はN/A）
6. **3年間総コスト**: 初回決済額 + (月額 x 36) で算出

## 注意事項

- 金額はすべて税込で入力してもらう
- 不明な項目は「未定」として記載し、後から更新可能
- リプレイスの並行稼働期間は月単位で計算（日割りは行わない）
- 生成後にユーザーが内容を確認し、修正があれば対話で更新する
