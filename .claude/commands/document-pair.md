# /document-pair - ドキュメント読み合わせペア決定

## 概要

DEVチームの「ドキュメント読み合わせ」運用で、本日の出勤者からペアを自動決定するコマンド。

**設計書:** `doc_draft/basic-design/ドキュメント読み合わせ運用/README.md`

## 使用方法

```
/document-pair
```

## 実行手順

### Step 1: 出勤者の選択

以下の7名のメンバーから、本日出勤している人を選択してもらう。
AskUserQuestion を使用し、multiSelect: true のチェックボックス形式で表示する。

**メンバー一覧:**

- 古谷
- 岡田
- 棟安
- 森下
- 村上
- 加古川
- 山野

質問文: 「本日出勤しているメンバーを選択してください」

### Step 2: バリデーション

- 選択された出勤者が **2名未満** の場合 → 「ペアを組むには2名以上の出勤が必要です。本日の読み合わせは中止してください。」と表示して終了

### Step 3: ペア生成

選択された出勤者をランダムにシャッフルし、以下のルールでペアを組む:

1. **出勤者が偶数の場合:** 全員を2人ずつのペアに分割
2. **出勤者が奇数の場合:** 2人ペアを基本とし、**最後の1組だけ3人組**にする

### Step 4: 結果表示

以下のフォーマットで出力する:

```
## 本日のドキュメント読み合わせペア（YYYY-MM-DD）

**出勤者:** [選択されたメンバーをカンマ区切りで列挙]

| ペア | メンバー |
|---|---|
| A | [名前] - [名前] |
| B | [名前] - [名前] |
| C | [名前] - [名前] - [名前] |

**読み合わせ時間:** 11:00 〜 11:30
**対象ドメイン:** 前回の続きから（進捗はSFの保有スキルで確認）
```

## ルール

- ペアは毎回ランダムに決定する（固定パターンにしない）
- 2人以上の出勤がないと実行不可
- 出力は簡潔にする（余計な説明を加えない）
